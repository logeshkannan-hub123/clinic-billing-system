# Feature Definition of Done

Before declaring an approved feature complete:

- [ ] Requirement and acceptance criteria are explicit.
- [ ] Ambiguous business rules were confirmed.
- [ ] Existing code was inspected before editing.
- [ ] Only approved scope was implemented.
- [ ] Input validation exists at the authoritative boundary.
- [ ] Authorization is enforced where required.
- [ ] Errors are handled safely.
- [ ] Financial calculations are deterministic and tested where applicable.
- [ ] Date/time behavior follows the project timezone policy.
- [ ] Relevant unit/integration tests were added or updated.
- [ ] Lint/format/typecheck passed where available.
- [ ] Relevant build/run/manual verification was performed where available.
- [ ] No secrets or real patient data were introduced.
- [ ] Final diff contains no unrelated changes.
- [ ] Security/privacy review was performed for sensitive features.
- [ ] Documentation was updated when behavior/configuration changed.
- [ ] Git status and branch were checked.
- [ ] Commit was created only if explicitly authorized.
